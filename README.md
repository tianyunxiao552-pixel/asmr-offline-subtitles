# 日语 ASMR 全离线自动字幕工具

推荐安装位置：`D:\ASMR-Offline-Subtitles`，也可将完整仓库放在其他普通本地目录。把完整音声文件夹放入 **待翻译**，双击 **run.bat**；整个作品完成后，它会连同原音频、封面、说明和字幕一起移入 **已翻译**。

```text
D:\ASMR-Offline-Subtitles\
├─ run.bat                 开始 / 续跑
├─ view_progress.bat       查看实时日志
├─ clean_models.bat        只清理下载的模型缓存
├─ 待翻译\作品A\
│  ├─ 封面.jpg
│  ├─ 01.wav
│  └─ CD2\02.wav
└─ 已翻译\作品A\           全部音轨成功后整包移到这里
```

首次安装与下载需要联网。模型准备完成后，`run.bat -Offline` 可完全离线处理；音频和字幕不上传，不调用在线听写或翻译服务。普通双击在缓存齐全时也直接使用本地模型。整包处理由用户双击或运行命令启动。

## 现在实际使用的质量方案

默认不再对原音做 UVR 分离。耳语的辅音可能被分离器削弱，因此使用原始音频听写，保留较长语义，再定位词时间。模型大小本身不保证在每段 ASMR 中表现最佳，请以实际试听为准。

| 环节 | 实际配置 |
|---|---|
| 耳语检测 | TransWithAI/Whisper-Vad-EncDec-ASMR-onnx，CPU，阈值 0.35，最短语音 100ms |
| 原音听写 | 完整 Qwen/Qwen3-ASR-1.7B-hf，BF16、CUDA、SDPA，固定日语，贪心解码 |
| 时间定位 | 完整 Qwen/Qwen3-ForcedAligner-0.6B-hf，BF16、CUDA，日语分词 |
| 本地翻译 | 官方 Sakura-14B-Qwen2.5-v1.0，Q4_K_M，经独立便携 Ollama 服务运行 |

VAD 将间隔不超过 2 秒的语音合并，边界补 400ms，每个听写窗口最多 30 秒；再按词时间和标点切成适合显示的字幕。重切必须保留听写文字，不能借机补写内容。ASR 与对齐器串行加载，结束后释放对象、执行垃圾回收与 CUDA 缓存清理；工作子进程退出后再加载翻译模型。

翻译固定使用 **14B Q4_K_M**，不再因显卡总显存不足 10GiB 自动换成 7B。Ollama 根据可用资源混合使用显存和系统内存，可能比小模型慢。ASR 留显存余量，空闲资源不足时明确报错并保留断点；不会偷偷降为小模型或 INT8。请关闭其他占显存的 AI 程序和游戏。

Sakura 本地名称为 `hf.co/SakuraLLM/Sakura-14B-Qwen2.5-v1.0-GGUF:Q4_K_M`。官方在线量化标签不可拉取时，下载同仓库的准确文件 `sakura-14b-qwen2.5-v1.0-q4km.gguf`，核验官方 SHA256 后本地导入；模型与量化规格不变。

源码仓库不附带任何模型、用户音频、字幕或对照视频。旧方案兼容代码不参与新版默认流水线，也不会在正常运行时重新下载旧权重。

每条音轨的 Ollama 服务和 `llama-server` 使用独立的 Windows 进程组管理。翻译后请求卸载，再终止并等待整棵自有进程树退出，检查显存回到翻译前附近（最多等待 20 秒）。下一次 ASR 加载前另有最多 30 秒的显存回收等待；仍不满足原来的完整模型预算才报错。不会结束其他软件的进程，不降低模型、精度或原有安全预算。

## 如何使用

1. 把整个作品文件夹放入 `待翻译`，可一次放多个。递归处理其中的 `.wav`；其他文件随整包保留。后缀为 WAV、实际为 M4A/MP3 的文件可由 FFmpeg 解码，原文件不改名、不改内容。
2. 双击 `run.bat`。窗口实时显示耳语检测、听写、时间定位、翻译进度。窗口误关后可双击 `view_progress.bat` 看日志；该窗口只看日志，不会启动或恢复任务。
3. 全部 WAV 生成有效中文字幕后，整包移到 `已翻译`。失败作品留在 `待翻译`，再次运行复用已完成音轨和有效断点。模型工作进程失败会停止队列，避免对后续音轨重复同一错误。
4. 播放音频时加载同名 `.srt`。以后每条音轨只新增一个中文字幕文件，拿走整个已翻译作品即可。

例如 `01.wav` 旁边只生成 `01.srt`（简体中文字幕）。不再自动生成 `.ja.srt`、`.bi.srt` 或 `.lrc`。日文听写保存在内部 `.state/<音轨键>/japanese.srt`，供翻译和断点续跑使用，随整包移动仍能定位。此前已有的字幕和对照样本保持原样，不会擅自删除。

SRT 使用 UTF-8 BOM、毫秒时间格式。时间格式精度不等于识别或对齐误差达到毫秒。字幕不会改变音频音质。

同名有效中文字幕表示已完成，默认跳过；只有日文听写缓存时继续翻译。工具生成的日文听写记录源文件和处理版本，旧版本会先备份再重听写；音频旁已有 `.ja.srt` 时兼容导入内部缓存，保留原字节以复用有效翻译断点，也保留原文件。更换同名源文件时，旧日文缓存会受到源文件检查。

已翻译中已有同名作品时停止该作品，不覆盖、不合并。音轨处理期间不要删除、改名或替换它。完整作品的封面和其他资产原样保留。散放 WAV 会自动归入作品子目录，但建议始终放入完整文件夹。

## 翻译与疑难片段

每批最多 20 个语义单元，同时按文本长度和长停顿缩小批次。前 5 句日文及已有译文作为已完成的历史对话，当前轮只输出新句。使用 Sakura v1.0 官方轻小说 System Prompt，并补充字幕口语规则：中文自然简洁，保留重复和省略，不编造剧情、动作或人物关系。

固定 `temperature=0.1`、`top_p=0.3`、`frequency_penalty=0.2`，上下文 6144 token，输出预算根据输入长度设置为 128～2048 token。时间轴不送给翻译模型。多句输出必须一一对应；错行或超限就拆小批，每个成功小批立即存断点。单个语义单元的显示换行可以合并；不靠补空句或截断文本伪造对齐。永久失败时保留诊断。

明显异常的听写，例如输出达到长度上限、长段机械重复或未返回可识别日文，会标为 `［聞き取り不明］`，中文为 `［听不清］`，候选文字保存在 `.state` 的质量报告。不能可靠对齐时保留粗时间并标记复核。未标记也可能有错，耳语、拟声词、双人重叠仍需人工判断；行数吻合不等于语义正确。

## 可用命令

在工具文件夹地址栏输入 `cmd`，再运行：

```bat
run.bat -Prepare
run.bat -Offline
run.bat -Diagnose -Offline
run.bat -SelfTest
run.bat -Rebuild -Offline
```

- `-Prepare`：下载并实际加载 ASR、VAD、对齐器及 Sakura；不开始作品。缓存已齐全时可加 `-Offline` 验证本地加载。
- `-Offline`：禁止必要文件的联网获取，缺失就报错。
- `-Diagnose`：检查 CUDA、依赖和所选模型，不处理作品。
- `-SelfTest`：执行自动化测试，不运行整包真实听写。无环境时仍需先联网安装便携 Python；数值和媒体测试需要已有依赖。
- `-Rebuild`：重做当前 **待翻译** 中的全部音轨。先验证模型可加载，再把旧字幕和对应断点移动到 `.state/<音轨键>/subtitle-history-时间/`，然后重新听写和翻译。不会自动重做已翻译中的作品；需要重做时先自行移回待翻译，确保成品目录没有同名冲突。

关闭运行窗口会终止本次工作进程；再次运行可以续接已保存片段，并不代表关闭后仍在后台翻译。强制结束时可能遗留 `.temp` 临时文件，可在确认工具关闭后删除该目录内残留。原音频始终保留。

## 清理与空间

双击 `clean_models.bat` 即删除本工具 **`.models` 整个目录**，包括新旧权重、下载缓存和未完成的分段下载。下次使用必须重新联网准备。清理与处理共用互斥锁，运行中不能清理；清理检查真实绝对路径，拒绝目录联接和符号链接。

| 目录 | 用途 | 一键模型清理 |
|---|---|---|
| `.models` | 全部本地模型权重及下载缓存 | 删除 |
| `.runtime` | 独立 Python、CUDA 库、FFmpeg、便携 Ollama | 保留 |
| `.state` | 断点、质量报告、旧字幕备份、诊断 | 保留 |
| `.logs` | 日志和验收记录 | 保留 |
| `.temp` | 中间音频 | 保留；当次正常处理结束会清理 |
| `待翻译`、`已翻译`、`效果对比` | 用户原音、字幕、资产、试听样本 | 保留 |

当前新版权重约 15GB；运行环境和音频另外占空间。清理显示实际释放量，不能保证固定 15～20GB。保留缓存可免重复下载，模型仍需从硬盘加载到内存，不能保证秒启动。

## 环境与验证

Windows 10/11 x64、NVIDIA CUDA GPU、16GB 以上内存，更多内存有助于 14B 混合运行。便携 Python 3.12.10；PyTorch 2.8.0 CUDA 12.8；ONNX Runtime GPU 1.22.0；Transformers 5.19.0。依赖使用固定版本，系统 Python 不受影响。不要另外安装 CPU `onnxruntime` 覆盖 GPU 模块；faster-whisper 的依赖声明可能提示缺 CPU 包，但实际使用的是 GPU 运行库。

自动测试覆盖文件夹流转、冲突、原文件保留、断点、重做回滚、译文错行、下载校验、原音默认路径、真实 M4A 解码和时间重切文字守恒。另有 90 秒真实音频的完整原音听写→时间对齐→Sakura 14B 翻译样本。工程测试验证行为，不证明每句翻译正确。

开发时曾使用本地音频比较旧分离 Whisper、原音 Qwen 短段和长语义对齐版；这些私人测试素材不随仓库提供。

下载与权重来自官方发布；模型和运行库不随工程源码压缩包分发。相关许可证以各仓库为准。
